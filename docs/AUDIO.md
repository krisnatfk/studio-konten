# Unggah audio manual

Dashboard: pilih file MP3 di bagian **Audio voice over**, tempel naskah agar subtitle sesuai, lalu klik **Buat video**. WAV dan M4A juga didukung.

Telegram: kirim naskah sebagai teks atau file `.txt`, lalu kirim MP3. Naskah disimpan selama satu jam untuk dipasangkan dengan audio. Naskah juga dapat dikirim pada caption audio.

Jika Whisper tidak aktif, naskah wajib disertakan. Render ulang memakai audio yang sudah tersimpan pada job.
